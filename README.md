# Smoke Machine

A browser tool for designing layered smoke and stage-light effects. Open `index.html` in any modern browser; no install or build step.

- **Smoke layers:** emitters with shape, rate, puffs, lifetime, size, colour, turbulence and more.
- **Light layers:** spotlights that colour the smoke beneath them, with aim, cone, reach and sweep.
- **Export:** copy embed code (a transparent canvas plus script), download a standalone page, PNG frame or WebM video.
- **Settings:** export and load settings as JSON.
